# AIDA64 网页兼容模式

手机仍可显示 AIDA64 RemoteSensor 等外部网页。此模式需要自行运行 AIDA64，与默认的曜屏 PC 采集模式分开；内置九套主题不改变外部网页样式。

## 使用

1. 在手机面板上向上滑动，打开设置并切换到 AIDA64 网页面板模式。
2. 输入电脑的 RemoteSensor 地址，例如 `http://192.168.1.20:8080/`。手机与电脑应处于同一可信局域网。
3. 按需设置工作日、周末 / 节假日屏幕计划，并允许精确定时权限。
4. 根据手机系统授予锁屏显示和后台运行权限，参见 [手机说明](android.md)。

外部网页模式按日程控制常亮 / 息屏，支持休息日与调休安排；请在设置中核对所需时段和节假日数据。息屏时长按可临时唤醒 10 分钟，亮度由系统管理。
