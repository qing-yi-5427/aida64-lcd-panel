# 曜屏 2.5.0：局域网联动

一个 PC 应用 + 一个 Android APK。PC 采集硬件与电脑电源状态，经局域网 HTTP/SSE 发送到手机；APK 使用内置 HTML/CSS 展示并控制亮灭屏。日常无需运行 AIDA64、HWiNFO 或 ADB。

## 2.4.2 内存优化

启动到托盘时不创建概览窗口；打开时才创建，关闭后释放界面，局域网连接与本次硬件授权继续有效。最小化时停止界面刷新，手机断联后切到后台采样速度；重新打开立即请求新读数。GC 限为一个堆并启用自适应节省内存策略，不绑定某个 CPU 核，不设易引发内存不足的硬性堆上限，也不强制清空工作集。仅在状态变化时生成新快照，传感器只保存最新值，不保留硬件库默认的一天历史。

基础采集也由同一 EXE 的普通权限子进程承担，主程序不加载显卡监控库。主动 UAC 授权成功后，以完整采集子进程替换基础子进程；取消授权仍保留原基础进程。切换通过关闭父进程拥有的生命期管道通知退出，不强杀采集器；父程序退出也会清理子进程。用户仍只启动一个程序，不需要安装新组件。

程序在初始化界面之前启用 Windows 的进程级旧式扩展点禁用策略，避免 RTSS 等全局窗口钩子被加载到曜屏及其采集进程中。只作用于曜屏自身，不修改 RTSS 配置、游戏帧率限制或系统全局设置，不需要 UAC。现代 TSF 中文输入法不受该策略限制；如需在曜屏使用依赖旧式钩子/旧式 IME 的工具，可在启动曜屏的进程环境中设置 `PANELDECK_ALLOW_LEGACY_HOOKS=1`，下次启动生效。

优化需完整退出旧版后启动新版才能生效。安卓协议保持兼容，现有 2.4.1 APK 无需升级或重新配对。完整授权进程的母板传感器占用必须在用户主动授权后测量，本次未自动弹 UAC。具体测量条件见 `research/memory-optimization-2.4.2.md`。

## 首次使用

### 发行包选择

- **精简版**：`./desktop/build-desktop.ps1 -FrameworkDependent`，固定输出 `artifacts/PanelDeck-Desktop-Lite/`，复用已安装的 x64 .NET 10 Desktop Runtime 和 ASP.NET Core Runtime。推荐打开 `PanelDeck.Launcher.exe`：组件齐全就启动主程序并退出；缺少时显示环境助手，主动点击“安装缺少的运行时”后才下载并请求管理员授权。此方式减少磁盘与分发体积，不代表运行内存按同样比例下降。
- **自包含版**：`./desktop/build-desktop.ps1`，附带所需 .NET 运行时，用于没有预装环境的电脑。
- 保留整个发行文件夹。运行环境齐全时也可直接打开 `PanelDeck.exe`。可选 `-IncludeDriver` 将 PawnIO 安装包一同分发；已安装驱动的本机无需重复携带安装包。更新固定目录前应从托盘退出曜屏，避免覆盖正在使用的文件。不要从旧自包含包合并复制到精简目录，否则旧运行时文件仍会占空间。

### 运行环境检测与安装

设置中的“运行环境”页显示共享运行时的版本、架构和发行模式，支持重新检测与打开安装助手。安装助手依赖受支持 Windows 自带的 .NET Framework 4，不依赖可能缺失的 .NET 10；缺少 .NET 10 时无法进入主程序设置，因此必须保留此启动前入口。助手安装完成后重新检测，点击“启动曜屏”继续；平时不常驻。

检测分别检查 x64 主机和 .NET 10 稳定版基础、桌面、ASP.NET Core 运行时，不将 x86、预览版或其他主版本视为满足条件，也不混用不同目录中的组件。自包含包无需安装共享运行时。微软安装程序安装到系统注册位置，自定义 DOTNET_ROOT 的不完整组件不会被误当作该位置已安装。

安装仅从微软 .NET 10 发布元数据获取最新稳定补丁的缺失组件，验证 SHA-512 和 Microsoft 数字签名后调用官方安装程序；不安装 SDK 或 IIS Hosting Bundle。多个缺失组件可能分别请求 UAC，使用 `/norestart`，取消、断网和校验失败均不会被视为成功。若部分组件已成功，重试时仅补剩余缺失项；重启要求会显示给用户，不自动重启。

1. 将完整 PC 发行目录放在固定位置，安装 `PanelDeck-Android-2.5.0.apk`。
2. 手机和 PC 接入同一可信局域网。PC 可以走有线网络，手机使用同网段 Wi-Fi。USB 只用于充电。
3. 打开 PC 设置，在“连接与配对”页点击“允许局域网连接…”。此按钮仅配置防火墙；硬件读取使用主界面单独的“授权完整读取（UAC）”。
4. `PanelDeck.exe` 默认只显示托盘图标，双击打开控制台；首次配置也可用 `PanelDeck.exe --show` 主动打开，再进入“设置与配对”。
5. 在“连接与配对”页选择电脑实际连接手机所在网络的地址；列出的 VMware/VPN 地址通常不是目标地址。在手机填该地址。在电脑点击“生成配对码”，将 8 位码填入 APK，点击配对，再保存手机设置。
6. 配对码单次有效，关闭 PC 设置页即失效。已配对手机用本地保存的长期令牌连接，无需反复配对。更改电脑 IP 后重新配对；建议在路由器中固定电脑的 DHCP 地址。

原 USB 版升级后必须在 APK 中设置局域网地址；旧 ADB 配对不会自动转成 LAN 配对。旧 PC 版仍运行时，新程序的单实例保护可能只打开旧版；切换前请从旧版托盘明确退出，再启动新版。

## 本次运行的硬件授权（推荐）

点击主界面“授权完整读取（UAC）”，在 Windows 弹窗中同意。本次运行内一直有效，不会每次采样重复弹窗；取消则继续基础采集。重复点击和授权等待期间不会重复创建请求。

同一个 PanelDeck.exe 启动临时采集进程，主界面与局域网服务保持普通权限。临时进程仅提供本机只读传感器管道，不监听网络；绑定主程序的进程与创建时间。关闭主窗口缩到托盘不算退出，完整退出曜屏后临时进程结束；下次启动需要重新主动授权。不注册常驻 Windows 服务，也不写入“永久管理员授权”。已安装的 PawnIO 驱动会复用，驱动本身不会随退出卸载。

权限不足造成的 CPU 温度/功耗、主板风扇缺失可通过授权读取。硬件或库不支持、未连接的传感器仍显示 `—`。若没有 PawnIO，会明确提示先安装驱动，不会在授权按钮里静默安装。

## 一次性配置

请在方便时通过设置中的配置按钮进行。只有主动点击并确认才会请求一次管理员授权；失败详情保存在 `%ProgramData%/PanelDeck/setup.log`。启动、采样和自动重连不会触发 UAC。也可以使用以下脚本进行维护。

### 局域网防火墙

在发行目录的管理员 PowerShell 中执行：

```powershell
./Configure-LAN.ps1 -Port 8080
```

只允许该发行目录中的 PanelDeck.exe，在 Windows 专用网络中接受本地子网访问。不会关闭防火墙或修改网络类别。端口、程序位置改变后需重新配置。电脑网络若是公用网络，不应为了方便直接放开所有网络；在可信家庭网络上由用户选择合适的网络配置。

### 常驻采集服务（兼容旧配置，可选）

```powershell
./Install-Collector.ps1
```

以下安装路径用于需要常驻服务的旧配置，日常使用推荐上面的“本次运行授权”。脚本会安装一个名为 `PanelDeckCollector` 的后台服务，服务文件复制到受保护的 `%ProgramFiles%/PanelDeck Collector`。服务以 LocalSystem 运行，通过本机只读命名管道输出传感器数据，无 HTTP 监听、手机控制、任意命令或客户端提供的路径。主程序仍以普通权限运行，通过服务取得 CPU 温度、功耗和主板风扇。

完整采集使用 LibreHardwareMonitorLib 0.9.6 与 PawnIO。脚本仅在 PawnIO 未安装且发行包包含经签名校验的官方安装程序时安装它。已有驱动会复用。服务没有请求时不持续采样；采样由主程序的设置驱动，最密不超过每秒一次。组件安装、升级需要管理员授权，日常不请求 UAC。

不安装服务时，主程序自动使用基础采集：CPU 使用率、内存以及显卡支持的指标。可通过主界面的 UAC 按钮授权本次完整读取。不可读取的 CPU 温度/功耗或主板风扇显示 `—`；不会用 0 冒充有效温度，也不会自动提权。

移除服务：`./Install-Collector.ps1 -Uninstall`。移除防火墙规则：`./Configure-LAN.ps1 -Remove`。移除服务不会卸载可能被其他软件共用的 PawnIO，也不会删除受保护的安装目录。

## 手机面板主题

手机面板上向上滑动，点击设置按钮，在“面板外观”选择主题。APK 2.5.0 保留经典、Material、WinUI、Flutter 卡片和 macOS 玻璃主题，并新增纸页、静夜、遥测、拼贴四种不同布局。主题选择框可滚动查看名称、说明和选中状态；“全屏预览 4 秒”会临时收起设置，即使电脑离线也可预览；保存后长期生效，取消会恢复原主题。无需重新配对。主题仅用于内置面板，AIDA64 外部网页由其自身决定样式。

四套新增布局支持横屏重排，手机遵循系统自动旋转设置。无额外动画、图表库、远程字体或联网资源，仍使用同一套硬件数据与屏幕联动协议。方案对比见 `artifacts/ui-2.5.0/index.html`（示例数据）。

温度、转速、频率等主要数值从设计画布的 54px 增大到 86px，标签和硬件型号同步放大。CPU 风扇统一显示 FAN 1，不改变实际传感器来源。玻璃主题使用静态渐变与高光，不持续运行背景动画或模糊合成。所有模式均已删除应用亮度控制，自动亮度由手机系统负责。

## PC 设置

### 网速监控

PC 2.5.0 以普通权限读取 Windows 活动物理以太网/Wi-Fi 收发计数，沿用已有采样周期，不新增定时器、驱动、进程或 UAC。手机九主题均显示上下行速率，并保留完整时间。统计包含局域网流量，排除 VPN 等虚拟网卡层的重复计数；首采、网卡变化与睡眠恢复先重建基线。没有有效读数时显示 `—`。详见 [实现与开销验证](research/network-monitor.md)。

APK 与旧版 PC 协议兼容，但网速需要运行 PC 2.5.0。若已有 PC 程序在运行，可先用 `./desktop/build-desktop.ps1 -FrameworkDependent -OutputDirectory artifacts/PanelDeck-Desktop-Update` 生成待更新包，再由用户完整退出旧版并替换固定目录。脚本会拒绝直接覆盖正在使用的 DLL，避免部分文件被更新。完整退出会结束本次硬件授权，网速本身不需要重新授权。

- **连接与配对**：监听地址、端口、当前手机连接地址、5 分钟临时配对码、撤销已配对手机。保存端口会重启本应用的网络监听，手机需同步更改地址。
- **手机屏幕**：电脑开机且未睡眠就亮屏，电脑锁屏、静置、游戏均不影响显示。亮度完全跟随手机系统（包括自动亮度），PC 不再提供或发送亮度设置。不读取键鼠输入，也不检测手柄或人体。
- **采集与运行**：手机连接时默认每 2 秒采样；息屏或手机未连接且控制台隐藏时每 15 秒采样。采集与电源状态分别运行，传感器读数延迟不会阻塞亮灭屏联动。还可复用已有后台采集服务，设置 CPU 风扇接口、登录启动和启动到托盘。
- **控制台**：自动、进入息屏、只读面板预览与导出读数。关闭窗口留在托盘，退出使用托盘菜单。

手动息屏持续到主动恢复“自动”。手机上的长按临时唤醒保留。断网时无法区分电脑关机与网络故障，因此统一等待 45 秒后进入息屏；恢复连接后自动显示。电脑端必须随登录运行，可以在设置中开启登录启动。Windows 尚未登录时只有采集服务在运行，不能直接联动手机。

## APK 自主管理屏幕

- **亮屏**：通过既有唤醒锁、锁屏显示和后台启动路径恢复窗口，复用 HyperOS 已授权能力。仅在需要从息屏恢复时触发，不因每帧数据抢占手机前台。
- **默认息屏**：黑色遮罩、取消常亮；联动模式不修改窗口亮度，再由 Android 系统超时真正关闭屏幕。系统超时时间不会被应用偷偷改动。
- **立即锁屏（可选）**：在 APK 设置中开启，Android 会要求用户授予设备管理中的“锁定屏幕”能力。授权后返回再打开开关并保存。仅申请 force-lock，不申请擦除数据等策略。锁屏可能要求凭据才能进入其他应用，面板可以在锁屏上显示。卸载 APK 前需先在系统设置停用此设备管理员。
- **断连**：界面标记过期，45 秒宽限后进入息屏。断线本身不会唤醒手机；连接恢复且 PC 状态为正在使用时恢复显示。电脑退出、休眠或断电通过连接状态处理，不能保证休眠前最后一条消息一定发出。
- **充电与功耗**：默认不持有持续的 CPU 唤醒锁。息屏时暂停页面计时器和渲染。若手机实际息屏后恢复延迟，可开启“充电时保持后台连接（兼容模式）”；它仅在充电且已连接电脑时维持 CPU 唤醒，增加耗电，失去连接或供电后最多约 20 秒释放。断网后的后台恢复仍受 Android/HyperOS 限制，不承诺所有系统下立即唤醒。
- **后台权限**：HyperOS 的锁屏显示、后台启动、唤醒和电池白名单可通过根目录 `configure-hyperos-adb.ps1` 一次性配置。APK 更新后若权限被系统重置才需要再次配置，日常不运行 ADB。

## 风扇识别

B650E AORUS ELITE X AX ICE 的名称在 LHM 0.9.6 映射表中漏了 X，因此返回 Fan #1～#6。暂按同系列映射显示 Fan #1 为 CPU_FAN，并标记“暂定”；主板同系列映射曾与 HWiNFO 对照，但尚未取得本机接口的精确实测确认。设置保存稳定传感器 ID，接口丢失不会自动改选其他高转速风扇。详见 [风扇接口调研](research/fan-mapping.md)。

## 数据边界

HTTP/SSE 只用于可信私有局域网，配对码/令牌不是传输加密。不开放公网、不做端口转发；应用拒绝公网来源 IP，防火墙示例进一步限制专用网络本地子网。传感器接口与恢复显示请求需要令牌，PC 浏览器的只读预览只允许回环地址。无云端账户或上传。

令牌存在 PC 的 `%LOCALAPPDATA%/PanelDeck/settings.json` 与 APK 私有设置里，请勿分享；导出硬件读数不包含令牌。采集只调用监控读取功能，不提供风扇曲线、频率或电压调节。

## 构建与验证

需要 .NET 10 SDK、Android SDK、JDK 17+。桌面默认发行包自带运行时，精简版复用系统运行时。

```powershell
dotnet run --project desktop/PanelDeck.Tests -c Release
dotnet run --project desktop/PanelDeck.WindowsTests -c Release
./gradlew.bat assembleDebug lintDebug
./desktop/build-desktop.ps1 -IncludeDriver
./desktop/test-android-policy.ps1
node desktop/test-panel.cjs
node desktop/test-panel-themes.cjs
```

默认 PC 输出 `artifacts/PanelDeck-Desktop-2.5.0/`，精简版输出 `artifacts/PanelDeck-Desktop-Lite/`，APK 输出 `app/build/outputs/apk/debug/app-debug.apk`。普通自动测试不安装组件、不改变防火墙、不操作现有 PC 程序。另有明确隔离的手机测试夹具：仅监听回环地址、发送合成数据，使用临时 ADB 转发验证 APK；它不属于产品运行方式。完整验收结果和未验证项见 [验证记录](VALIDATION.md)。
